# Chat P2P Hybrid

## 1. Cách chạy (Linux)
1. `./build.sh` : Biên dịch ứng dụng.
2. `./run_server.sh` : Bật Server trung tâm -> bấm **Start Server**.
3. `./run_client.sh` : Mở Client (mở nhiều terminal để tạo nhiều Client).

## 2. Cách dùng
- Khi mở Client, pop-up hiện lên hỏi **Tên** và **Cổng P2P** (cổng đã tự động gợi ý, không bị trùng).
- Bấm **Vào Chat** để vào màn hình chính.
- Danh sách bên trái chỉ hiện người khác (không hiện chính mình).
- Chọn người cần chat, gõ tin nhắn và bấm **Gửi (P2P)** hoặc bấm phím **Enter**.
