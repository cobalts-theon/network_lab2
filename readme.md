# Chat P2P Hybrid

## 1. Chạy trên Linux (Terminal)
Bạn có thể chạy bằng lệnh `.sh` (chuẩn) hoặc gõ thẳng file `.bat`:
- Biên dịch: `./build.sh` (hoặc `./build.bat`)
- Bật Server: `./run_server.sh` (hoặc `./run_server.bat`)
- Bật Client: `./run_client.sh` (hoặc `./run_client.bat`)

## 2. Chạy trên Windows
- Biên dịch: Nhấp đúp vào `build.bat`
- Bật Server: Nhấp đúp vào `run_server.bat`
- Bật Client: Nhấp đúp vào `run_client.bat` (mở nhiều lần để tạo nhiều Peer)

## 3. Cách dùng
- Mở Client: Nhập Tên và Cổng P2P (được tự động gợi ý) rồi bấm **Vào Chat**.
- Danh sách chỉ hiện người khác. Chọn người nhận và gửi tin nhắn P2P trực tiếp.
